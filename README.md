# 나의 개발 환경 구축 프로젝트 
## 프로젝트의 목표 
Powershell과 VS Code를 사용하여 개발 환경을 익히고 웹페이지를 만들었습니다. 

## 사용한 프로그램 
- Windows 
- PowerShell 
- Visual Studio Code 

## 실습 내용 
1. 폴더와 파일 생성 
2. 파일 목사, 이동 및 삭제 
3. HTML 웹페이지 작성 
4. 웹페이지 제목 수정 및 결과 확인  

## 실습 결과  
- HTML 파일을 브라우저에서 열고 제목이 변경되는 것을 확인했습니다. 
- PowerShell을 이용한 파일 관리 실습 
- VS Code에서 HTML 파일 작성 및 실행 
- Git을 이용한 버전 관리 
- GitHub저장소 생성 및 업로드 

## 실습 중 제한 사항  
- 도커 관련 실습은 현재 컴퓨터 환경의 제약으로 진행하지 못함 
- 도커 이미지, 컨테이너, 볼륨 실습은 미완료
